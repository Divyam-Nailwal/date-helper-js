# Changelog

All notable changes to `@shukracharya/date-helper-js` will be documented in this file.

## [1.0.0] - 2026-11-22

### Added
- Core date formatting utilities: `formatDate`, `getCurrentDate`, and `getCurrentTime`.
- Difference calculation utilities: `getDateDifference`, `daysBetween`, `hoursBetween`, `minutesBetween`, and `secondsBetween`.
- Date manipulation utilities: `addDays`, `subtractDays`, `addHours`, `addMinutes`, `addMonths`, and `addYears`.
- Relative time formatting: `timeAgo` and `timeUntil`.
- Date validation functions: `isValidDate`, `isToday`, `isPastDate`, `isFutureDate`, `isSameDay`, and `isLeapYear`.
- Chronological comparison utilities: `isBefore`, `isAfter`, and `isBetween`.
- Full test coverage powered by Vitest.
